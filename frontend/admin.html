Not hearing your desktop notifications? That sound is chosen by your operating system, not by this page — the web Notification API has no working sound option in Chrome. On macOS enable it under System Settings → Notifications → Google Chrome (set the alert style to Banners or Alerts and tick Play sound for notifications). Also make sure Do Not Disturb / Focus is off. The toggle above is separate: it is the in-page chime, which this dashboard controls directly.

Notifications arrive whenever a customer submits an order — even when this tab is closed, as long as Chrome is running. Requires HTTPS (localhost works for testing).
